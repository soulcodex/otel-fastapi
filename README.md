# 🚀 OTEL FastAPI

##### A sample FastAPI application instrumented with OpenTelemetry for tracing and metrics collection.

---

### 🧾 Requirements:

- Go >= 1.25
- just (see the top-level `justfile` for available commands)
- Docker (docker & docker-compose / Docker Compose v2)

---

### ▶️ Run:

```bash
just up
just run-fast-api
```

---

### ⏹️ Stop:

```bash
just down
```
